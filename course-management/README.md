# إدارة المواد الدراسية (Course Management) — Prototype

نظام منفصل عن نظام القاعات، ومسؤول عنه الأقسام وشئون الطلاب. بيدير المواد المطروحة لكل فرقة، ومجموعاتها ومحاضريها ومتطلباتها، وبيبعتها لنظام القاعات كحصص محتاجة أماكن.

## التشغيل

افتح https://moatasemkamal.github.io/Team4/course-management/ أو `index.html` في أي متصفح. البيانات تجريبية ومتخزنة في المتصفح، وزرار "رجّع البيانات التجريبية" بيمسحها.

## الشاشات

| الشاشة | المحتوى |
| --- | --- |
| المواد حسب الفرقة | تبويب لكل فرقة: المواد المطروحة، الساعات المعتمدة، ساعات التدريس، الحصص المحتاجة أماكن، والتنبيهات |
| تفاصيل المادة | عدد الطلاب، طريقة التدريس لكل نوع حصة، الدكتور، المجموعات ومعيد كل مجموعة، والمتطلبات (إلزامي بسبب مكتوب) |
| كتالوج المواد | كل مواد اللائحة بالفرقة والفصل، وإضافة مادة جديدة وطرحها في الترم |
| أعباء التدريس | ساعات كل دكتور ومعيد في الأسبوع مقابل الحد الأقصى |
| الإرسال لنظام القاعات | حالة كل مادة (ماتبعتتش / اتبعتت / اتغيرت بعد الإرسال)، والتغييرات، وشكل البيانات المرسلة |
| الإعدادات | الحد الأقصى لحجم مجموعة السكشن والمعمل، والحد الأقصى للعبء |

## القواعد

- المحاضرة بتبقى حصة واحدة لكل الطلاب. السكاشن والمعامل بتتقسم مجموعات: عدد الطلاب ÷ الحد الأقصى للمجموعة، والتقسيم بالتساوي. ممكن تثبيت عدد المجموعات يدوي.
- المادة مش بتتبعت لنظام القاعات لو ناقصها: عدد الطلاب، أو دكتور المحاضرة، أو معيد لأي مجموعة، أو سبب لمتطلب إلزامي.
- تجاوز الحد الأقصى للعبء أو حجم المجموعة بيظهر كتحذير بس، ومش بيمنع الإرسال.
- أي تعديل بعد الإرسال بيظهر كـ "اتغيرت بعد الإرسال" مع قائمة التغييرات، ولازم يتبعت كتحديث.

## البيانات المرسلة لنظام القاعات

لكل مادة مطروحة: الترم، والمادة (الكود والاسم والقسم والساعات)، والفرقة، وقائمة حصص. كل حصة فيها:

| الحقل | المعنى |
| --- | --- |
| `ref` | معرّف ثابت للحصة، مثلاً `IS220-lab-G2` |
| `kind` | `lecture` / `section` / `lab` |
| `group` | `all` للمحاضرة، أو `G1`… |
| `students` | عدد طلاب الحصة |
| `sessionsPerWeek`, `hoursEach` | عدد المرات في الأسبوع ومدة كل مرة |
| `deliveryMode` | `inperson` / `online` / `hybrid` |
| `needsRoom` | `false` لو أونلاين |
| `instructor` | الدكتور أو المعيد |
| `requirements` | الأداة، إلزامي أو لأ، والسبب. مفاتيح الأدوات نفسها في النظامين |

الموعد (اليوم والفترة) مش جزء من البيانات دي. الحصص الجديدة بتوصل نظام القاعات "محتاجة موعد"، وموظف التوزيع بيحدده لحد ما يتحدد مين مسؤول عن الجدول.

## الربط مع نظام القاعات

- الإرسال بيوصل لنظام القاعات فوراً لو مفتوح في نفس المتصفح ومن نفس الموقع.
- عمود "التوزيع" بيعرض اللي نظام القاعات رجّعه: كام حصة اتوزعت من المطلوب، وتفاصيل كل حصة (المكان والموعد) جوه المادة.
- إلغاء طرح مادة اتبعتت قبل كده بيبعت إلغاء لنظام القاعات عشان يفضّي أماكنها.
- في النسخة الحقيقية الربط ده بيبقى API بين النظامين.
