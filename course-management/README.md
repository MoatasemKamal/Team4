# إدارة المواد الدراسية (Course Management) — Prototype

نظام منفصل عن نظام القاعات، والمسؤول عنه الأقسام وشئون الطلاب في **كلية إدارة الأعمال — جامعة الإسكندرية**. كل الأقسام والبرامج والمواد وأعضاء هيئة التدريس مربوطين بالكلية، فكليات تانية في الجامعة ممكن تستخدم النظام بعدين.

## التشغيل

افتح https://moatasemkamal.github.io/Team4/course-management/ أو افتح `index.html` في أي متصفح. البيانات تجريبية ومتخزنة في المتصفح، وزرار "رجّع البيانات التجريبية" بيمسحها.

## الهيكل

| المستوى | المحتوى |
| --- | --- |
| الجامعة والكلية | جامعة الإسكندرية، كلية إدارة الأعمال (كلية واحدة مفعّلة دلوقتي) |
| الأقسام العلمية | المحاسبة، إدارة الأعمال، الاقتصاد، نظم المعلومات الإدارية، الإحصاء والرياضة والتأمين. القسم بيملك المواد والمحاضرين |
| البرامج | البرنامج العربي، البرنامج الإنجليزي، الساعات المعتمدة، الانتساب، دبلومة الدراسات العليا، الماجستير، MBA |
| الفرق والمستويات | 4 فرق، أو 4 مستويات في الساعات المعتمدة. الدراسات العليا من غير فرق |
| الشعب | من الفرقة التالتة: محاسبة، إدارة أعمال، اقتصاد، نظم معلومات (العربي)، ومحاسبة وإدارة أعمال (الإنجليزي) |
| مجموعة الطلاب | برنامج + فرقة + شعبة، وليها عدد طلاب. عليها بيتحسب تعارض الطلاب |
| تفاصيل المواد | الكود، والقسم، والساعات، وخطة التدريس، والمتطلبات |
| الخطة الدراسية (اللائحة) | لكل برنامج: المواد في كل فرقة أو مستوى وكل فصل دراسي، إجبارية ولا اختيارية، والشعبة، والمتطلب السابق، وعدد المواد الاختيارية اللي الطالب بياخدها |
| إضافة المادة للترم | مادة لجمهور (مجموعة طلاب أو أكتر)، وعدد الطلاب، ومجموعات المحاضرة، والسكاشن والمعامل جوه كل مجموعة، والمحاضرين |

## الشاشات

| الشاشة | المحتوى |
| --- | --- |
| المواد حسب البرنامج والفرقة | اختيار البرنامج والفرقة والشعبة، ومجموعات الطلاب وأعدادها، ومواد الخطة الدراسية اللي لسه ماتضافتش للترم (مقترحة)، والمواد المتضافة للترم وحالة إرسالها وتوزيعها |
| تفاصيل المادة في الترم | الجمهور، وعدد الطلاب، ومجموعات المحاضرة ودكتور كل مجموعة، والسكاشن والمعامل ومعيد كل واحد، وخطة التدريس، والمتطلبات، وحالة التوزيع |
| تفاصيل المواد | كل مواد اللائحة والقسم المالك وخطة التدريس، والبرامج اللي المادة متضافة للترم لها، وإضافتها للترم لجمهور جديد |
| الخطط الدراسية | خطة كل برنامج مقسّمة بالفرق والفصول: إضافة مادة، وتعديلها، وشيلها، واسم اللائحة. والمتطلب السابق بيتعلّم لو مش قبل المادة في الخطة |
| البيانات الأساسية | الكلية، والأقسام، والبرامج ومجموعات الطلاب وأعدادها، والشعب، والفصول الدراسية والترم الحالي، والأدوات (من نظام القاعات)، وأنواع الحصص وطرق التدريس. إضافة وتعديل، والحذف بس للي مش مستخدم |
| أعباء التدريس | ساعات كل عضو هيئة تدريس في الأسبوع من كل البرامج، مقابل الحد الأقصى لدرجته الوظيفية. أعضاء هيئة التدريس ودرجاتهم بيتعرفوا في module شئون أعضاء هيئة التدريس، والنظام ده بيقراهم بس |
| الإرسال لنظام القاعات | حالة كل مادة متضافة للترم، والتغييرات بعد الإرسال، وشكل البيانات المرسلة |
| الإعدادات | الحد الأقصى لمجموعة المحاضرة والسكشن والمعمل |

## القواعد

- **مجموعات المحاضرة:** عدد الطلاب ÷ حد المحاضرة (350)، بالتساوي. مثلاً 600 طالب يبقوا مجموعتين، 300 لكل واحدة.
- **السكاشن والمعامل** بتتقسم جوه كل مجموعة محاضرة بحد 55 للسكشن و35 للمعمل. والعدد ممكن يتثبت يدوي.
- **المادة الواحدة في الترم ممكن تخدم أكتر من شعبة.** مثلاً إدارة التسويق لكل شعب الفرقة التالتة.
- **المادة اللي بتتدرس عربي وإنجليزي** مسجلة مادتين في تفاصيل المواد (ACC101 وACC101E).
- **الإضافة للترم من الخطة:** شاشة المواد حسب البرنامج والفرقة بتقترح مواد الخطة للفرقة والترم الحالي، والموظف بيضيفها واحدة واحدة أو "إضافة كل الإجباري للترم". المادة المشتركة بين شعب بتتضاف مرة واحدة لكل الشعب اللي هي في خطتها.
- **من برة الخطة:** ينفع تتضاف للترم، بس بتظهر بعلامة "من برة الخطة" وتحذير.
- **المواد الاختيارية:** عدد طلابها متوقع (مبدئياً: الطلاب × عدد الاختياري المطلوب ÷ عدد المواد الاختيارية)، والموظف يعدّله لحد ما التسجيل الفعلي يوصل.
- **فصل المادة في الخطة** ممكن يختلف من برنامج للتاني، والإضافة للترم بتاخد فصل الخطة.
- **الانتساب** محاضراته أونلاين افتراضياً.
- **الإرسال بيتمنع** لو ناقص: عدد الطلاب، أو محاضر لأي مجموعة، أو سبب لمتطلب إلزامي، أو لو الخطة أطول من الترم.
- **التحذيرات مش بتمنع الإرسال:** تجاوز العبء، أو حجم مجموعة أكبر من الحد، أو عدد طلاب مختلف عن مجموع الجمهور.
- **التعديل بعد الإرسال** بيظهر "اتغيرت بعد الإرسال" مع قائمة باللي اتغير، ولازم يتبعت كتحديث.

## البيانات المرسلة لنظام القاعات

لكل مادة متضافة للترم: الترم، والكلية، والمادة، والبرنامج، والجمهور (`audiences`)، وعدد مجموعات المحاضرة، وقائمة حصص. كل حصة فيها:

| الحقل | المعنى |
| --- | --- |
| `ref` | معرّف ثابت للحصة: كود المادة + البرنامج + المجموعة، مثلاً `ACC101-AR-L2-S3` |
| `kind` | `lecture` / `section` / `lab` |
| `group` / `parentGroup` | `L1` لمجموعة محاضرة، و`L1-S2` للسكشن 2 فيها، و`L1-M1` للمعمل 1 فيها |
| `lectureGroups` | عدد مجموعات المحاضرة في المادة |
| `students` | عدد طلاب الحصة |
| `totalSessions`, `fromWeek`, `toWeek` | عدد المرات في الترم وأسابيعها |
| `sessionsPerWeek`, `hoursEach` | المرات في الأسبوع ومدة كل مرة |
| `deliveryMode`, `needsRoom` | `inperson` حضوري / `online` أونلاين / `hybrid` حضوري - أونلاين، وهل محتاجة مكان |
| `instructor` | الدكتور أو المعيد |
| `requirements` | الأداة، إلزامي أو لأ، والسبب. مفاتيح الأدوات نفسها في النظامين |

نظام القاعات بيحسب تعارض الطلاب من الجمهور والمجموعة، على افتراض إن مجموعة 1 هي نفس الطلاب في كل المواد (سؤال E4).
